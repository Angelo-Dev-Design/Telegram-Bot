# Telegram Bot
A multi-feature Telegram bot bulit with python
## Features
- Ai image generation,
- 4 decent and fun games
- a password manager
- a general notes app
- a solid calculator
- a multiplication table
- a password generator
- a option where you can see the time
- a fake news generator to prank your friends
- Guess the Number game
- Rock paper scissors
- Heads or tails
- And a miniature murder mystery quest

### Technologies
-Python
Telegram Bot API
Extensive API integration
JSON

### About
This project is a multi-purpose Telegram Bot that combines automation,games, AI tools and utility features in one application
